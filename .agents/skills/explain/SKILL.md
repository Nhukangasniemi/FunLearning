# Explain Feature

Explains what changed, why architectural decisions were made, and documents the feature.

## Instructions

1. **Inspect Modified Files**:
   - Identify all newly created and modified files related to the current feature.
   - Summarize the role of each change.

2. **Update [current-feature.md](../../rules/current-feature.md)**:
   - Add concise technical explanations under `## Notes` detailing:
     - Non-obvious decisions or tradeoffs.
     - Integration points (APIs, state management, UI components).
     - Any follow-up recommendations.

3. **User Summary**:
   - Provide a clear, bulleted walkthrough with clickable file links for the user.
